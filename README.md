# atproto-science

Shared coordination hub for the ATScience x IOSP side event at AtmosphereConf 2027 (Netherlands, 29-30 April 2027).

- `.beans/` holds the team's tasks (prefix `guus-`), run `beans list` from this directory. Epic: `guus-35aw`.
- `docs/` holds the overview, the repos list for the 4 Nov meeting, and a Notion-importable copy of the overview.

Personal notes and anything about individual employment or funding stay out of this repo.

## Collaborating

Clone, then work on a branch (or a git worktree), and open a PR against `main`. Agents and humans follow the same rules, see `CLAUDE.md`.
